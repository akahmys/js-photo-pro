# 日本下水道事業団（JS）電子納品基準の概要

本ドキュメントは、日本下水道事業団（JS）の工事完成図書および工事記録写真に関する電子納品基準の概要をまとめたものです。
AIおよび開発者が本プロジェクトでJS仕様の電子納品機能やバリデーションを実装する際の参照基盤として使用します。

## 1. 全体構造と構成ファイル

JSの電子納品は、国土交通省の電子納品基準をベースにしつつ、**JS独自の管理ファイル**を追加して構成します。

### 納品メディアのフォルダ構成（写真納品の場合の例）
```
[ルートフォルダ] (例: CD-R/DVD-Rの直下)
 ├─ INDEX_C.XML        (国交省仕様: 工事管理ファイル)
 ├─ IND_C04.DTD        (国交省仕様: DTD定義ファイル)
 ├─ INDEX_CJ.XML       (JS独自仕様: JS工事管理ファイル) ★必須
 ├─ IND_CJ01.DTD       (JS独自仕様: DTD定義ファイル)     ★必須
 ├─ DRAW_JS.XML        (JS独自仕様: 図面管理ファイル)     ※図面納品時必須
 ├─ DRW_JS01.DTD       (JS独自仕様: DTD定義ファイル)     ※図面納品時必須
 └─ PHOTO/             (写真フォルダ)
     ├─ PHOTO.XML      (写真管理ファイル)
     ├─ PHOTO.DTD      (写真DTD定義ファイル)
     └─ PIC/           (写真JPEGファイル格納先)
```

## 2. 国土交通省基準との主な相違点

1. **`INDEX_CJ.XML` の追加必須化**
   通常の `INDEX_C.XML` に加え、JS独自の工事情報属性（下水道根幹施設名、プロジェクトコードなど）を記述した `INDEX_CJ.XML` をルート直下に格納しなければなりません。
2. **`DRAW_JS.XML` の追加（図面がある場合）**
   図面を納品する場合、通常の `DRAWINGS.XML` に加え、JS独自の図面属性を記述した `DRAW_JS.XML` をルート直下に格納しなければなりません。
3. **適用要領の年度確認**
   契約年度によって適用される要領のバージョンが異なります（例：令和6年4月版など）。
