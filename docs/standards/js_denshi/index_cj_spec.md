# JS工事管理ファイル (INDEX_CJ.XML) 仕様定義

本ドキュメントは、日本下水道事業団（JS）独自の工事管理ファイルである `INDEX_CJ.XML` のタグ構成、DTD（`IND_CJ01.DTD`）に関連する要素、およびデータ入力時のルールを定義したものです。

## 1. 主要なデータ項目と入力規則

`INDEX_CJ.XML` に記述される主なJS独自属性と、その入力規則は以下の通りです。

| タグ名（要素名） | 論理名 | 入力形式 / 規則 |
| :--- | :--- | :--- |
| `<下水道根幹施設名>` | 下水道根幹施設名 | 施設名称を記入（例：`〇〇浄化センター`）。<br>**※複数施設を含む場合は、半角カンマ（`,`）で区切って記述する。** |
| `<プロジェクトコード>` | プロジェクトコード | JSから提示されるプロジェクトコードを半角英数字で入力。 |
| `<都市名>` | 都市名 | 工事実施対象の都市名（例：`〇〇市`）。 |
| `<工事番号>` | 工事番号 | JSの契約における工事番号。 |
| `<発注者コード>` | 発注者コード | JSが定義する発注者・担当事務所のコード。 |

## 2. 複数施設記述ルールの改定（令和6年4月改定）

令和6年4月（2024年4月）の要領改定に伴い、以下のルールが適用されます。
* **対象属性**: `下水道根幹施設名`
* **変更点**: 1つの工事契約で複数の処理場やポンプ場などの施設（下水道根幹施設）が含まれる場合、これまでは代表する1施設のみの記載や個別の対応が必要でしたが、改定後は該当するすべての施設名を **半角カンマ（`,`）** で区切って併記するルールとなりました。
* **例**: `<下水道根幹施設名>中央浄化センター,東部ポンプ場</下水道根幹施設名>`

## 3. バリデーションチェック時の確認事項

将来的に本アプリで電子納品用XMLのバリデーションや出力をサポートする場合、以下のロジックを実装する必要があります。
1. **DTD準拠性**:
   `INDEX_CJ.XML` のヘッダー部で `IND_CJ01.DTD` が正しく宣言されていること。
2. **カンマ区切りの妥当性**:
   `下水道根幹施設名` 内に全角カンマ（`，`）が使われていないかチェックし、半角カンマ（`,`）に変換または警告を出す。
3. **文字コード**:
   XMLの出力エンコーディングは `Shift_JIS`（または `UTF-8` 要領の指定に準拠）かつ、文字化けを防ぐ処理を通すこと。
